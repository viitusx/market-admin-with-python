# Market System in Python

A market system developed in Python with a focus on **Object-Oriented Programming**, clean code, and best practices.  
The project simulates a basic shopping flow via the terminal, including product registration, shopping cart management, and order checkout.

This repository is intended for **educational and demonstration purposes**, showcasing fundamental Python concepts and project organization.

---

## Overview

The system allows users to interact with a terminal-based menu to manage products and perform purchases.  
The application is organized into modules and uses classes, static typing, and encapsulation to ensure clarity, scalability, and maintainability.

---

## Features

- Product registration with automatic code generation  
- Listing of registered products  
- Add products to a shopping cart  
- View shopping cart contents  
- Order checkout with total price calculation  
- Interactive terminal menu  

---

## Concepts and Best Practices

- Object-Oriented Programming (OOP)  
- Encapsulation with private attributes  
- Use of `@property`  
- Static typing with `typing`  
- Modular project structure  
- PEP 8 coding standards  
- Separation of concerns

# Sistema de Mercado em Python

Sistema de mercado desenvolvido em Python com foco em **Programação Orientada a Objetos**, código limpo e boas práticas.  
O projeto simula um fluxo básico de compras via terminal, incluindo cadastro de produtos, gerenciamento de carrinho e fechamento de pedido.

Este repositório tem finalidade **educacional e demonstrativa**, apresentando conceitos fundamentais de Python e organização de projetos.

---

## Visão Geral

O sistema permite que o usuário interaja com um menu no terminal para gerenciar produtos e realizar compras.  
A aplicação é organizada em módulos e utiliza classes, tipagem estática e encapsulamento para garantir clareza, escalabilidade e fácil manutenção.

---

## Funcionalidades

- Cadastro de produtos com geração automática de código  
- Listagem de produtos cadastrados  
- Adição de produtos ao carrinho de compras  
- Visualização dos itens no carrinho  
- Fechamento do pedido com cálculo do valor total  
- Menu interativo no terminal  

---

## Conceitos e Boas Práticas Aplicadas

- Programação Orientada a Objetos (POO)  
- Encapsulamento com atributos privados  
- Uso de `@property`  
- Tipagem estática com `typing`  
- Estrutura modular do projeto  
- Padrão de codificação PEP 8  
- Separação de responsabilidades
